## Retrospective

### What went well

- Working compiler established.
- Reference validation caught invalid PNG transparency and canvas size.
- Local Python and GitHub Desktop workflow established.
- Repository now executes real validation logic.

### What did not go well

- Too many planning responses occurred before executable work.
- Placeholder files were treated as complete because they existed.
- Early image generation bypassed repository controls.

### Improvements

- Prefer executable increments over extended architecture discussion.
- Validate file content, not just existence.
- Do not generate production assets outside the approved build pipeline.
- Keep each sprint focused on one measurable outcome.
