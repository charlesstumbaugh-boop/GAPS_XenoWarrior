## GAPS 1.0 Release Criteria

- New user can install and run GAPS from documentation.
- Validation runs locally and on GitHub.
- Build requests compile without handwritten prompts.
- References and Gold Masters are validated.
- One complete asset lifecycle is demonstrated.
- One Unity-ready output is demonstrated.
- Release package, version, changelog, and license are present.
