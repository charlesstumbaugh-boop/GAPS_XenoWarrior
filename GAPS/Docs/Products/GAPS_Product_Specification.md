# GAPS Product Constitution

## Mission

Provide a professional, repeatable, non-destructive production engine for creating, calibrating, rigging, animating, validating, and exporting reusable game assets.

## Core Principles

1. Approved artwork is never modified.
2. Every stage is reproducible.
3. Every output is versioned.
4. Every stage has validation.
5. Every asset has a manifest.
6. Every operation is non-destructive.
7. Projects are independent from the engine.
8. The engine owns the workflow.
9. The engine guides the user.
10. Every release is recoverable.
