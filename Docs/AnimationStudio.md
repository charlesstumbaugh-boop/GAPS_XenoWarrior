# GAPS Animation Studio v0.1.0

Visual pose/timeline editor built on the promoted calibrated rig.

Features: six default frames, timeline, add/duplicate/delete, play/stop, onion-skin previous/next, drag, nudge, rotate, scale, save/load YAML, export PNG frames, horizontal sprite strip, and GIF preview. Approved source PNGs are never overwritten.

Launch from repository root:

```cmd
python Tools\AnimationStudio\animation_studio.py
```

Outputs are stored under:

```text
Production\CHR-GRUNT-001\06_Animations\<AnimationName>\
```
